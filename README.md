# Underworld Lords 🎮

A browser-based multiplayer crime game inspired by classic mafia strategy games. Build your empire, command your forces, and rule the underworld.

## 🚀 **Live Demo**
- **Frontend (GitHub Pages):** [https://ztrix1.github.io/underworld-lords-game/](https://ztrix1.github.io/underworld-lords-game/)
- **Backend API (Render):** [https://underworld-lords-server.onrender.com](https://underworld-lords-server.onrender.com) (إذا كنت نشرته)

## 📖 **About The Project**
Underworld Lords is a turn-based strategy game where players build criminal organizations, compete for territory, and engage in tactical combat. The game features user authentication, persistent profiles, and real-time multiplayer (coming soon).

### ✨ **Features Implemented**
- ✅ User registration & login (JWT authentication)
- ✅ MongoDB integration (MongoDB Memory Server for development)
- ✅ RESTful API with Express
- ✅ Responsive frontend (HTML, CSS, JavaScript)
- ✅ Auto-save to GitHub via PowerShell script
- ✅ Deployed frontend on GitHub Pages
- ✅ (WIP) Backend deployment on Render

### 🛠️ **Tech Stack**
- **Frontend:** HTML5, CSS3, JavaScript
- **Backend:** Node.js, Express.js
- **Database:** MongoDB (MongoDB Atlas for production, Memory Server for dev)
- **Authentication:** JWT, bcrypt
- **Real-time (future):** Socket.io
- **DevOps:** Git, GitHub Actions, Render, Ngrok
